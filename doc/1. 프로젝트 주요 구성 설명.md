## 2. 주요 도메인 관계 클래스 다이어 그램

* **DownEventCard** : 장비 down 이벤트 이력 ( Text )
* **DownEventContent** : 장비 down 현상 및 조치 상세 내용 ( html )
* **AttachedFile** : html 에 삽입한 이미지파일 정보  

```mermaid
classDiagram
+    direction LR
    class DownEventCard {
        <<interface>>
        +string downEventId
        +string equipmentId
        +string chamberId
        +FabricationPlant fabricationPlant
        +ProcessModule processModule
        +EquipmentModel equipmentModel
        +DownType downType
        +WorkStatus workStatus
        +number downStartDatetime
        +number downEndDatetime
        +number downDurationMinutes
        +boolean isCritical
        +string downCode
        +string downCodeDescription
        +string alarmId
    }

    class DownEventContent {
        <<interface>>
        +string downEventId
        +string contentHtml
        +string createdBy
        +string createdAt
        +string updatedBy
        +string updatedAt
    }

    class AttachedFile {
        <<interface>>
        +string fileId
        +FileRefType refType
        +string refId
        +string originFileName
        +string storedFileName
        +string filePath
        +number fileSize
        +string contentType
        +FileStatus status
        +string createdBy
        +string createdAt
        +string updatedBy
        +string updatedAt
    }

    DownEventCard "1" -- "1" DownEventContent : downEventId
    DownEventCard "1" <-- "0..*" AttachedFile : refId
    DownEventContent "1" <-- "0..*" AttachedFile : refId
```

## 3. 주요 처리 흐름도

① 검색조건으로 **`DownEventCard 리스트 페이징`** 추출 (Text 데이터)

② **`TanStack Virtualizer로 화면 Rendering`**
   - 사용자 모니터 세로 높이를 고려한 Rendering 을 위한 **`식별자 downEventIds`** 추출
   - Rendering  대상 downEventIds 로 **`DownEventCard(Text) / DownEventContent(html)추출하는 API`** 호출

③ 각 DownEventCard Element Rendering 시 **`html 의 여러 이미지 추출하는 API`** 호춯 

```mermaid
sequenceDiagram
    autonumber

    actor User as 사용자
    participant Page as 화면
    participant CardAPI as DownEventCard API
    participant Virtualizer as TanStack Virtualizer
    participant ContentAPI as DownEventContent API
    participant ImageAPI as 이미지 API

    rect rgb(235, 245, 255)
        Note over User,CardAPI: ① 검색조건으로 DownEventCard 리스트 페이징 추출
        User->>Page: 검색조건 입력 및 조회
        Page->>CardAPI: 검색조건 + page + pageSize 요청
        CardAPI-->>Page: DownEventCard 리스트(Text 데이터) 반환
    end

    rect rgb(240, 255, 240)
        Note over Page,ContentAPI: ② TanStack Virtualizer로 화면 Rendering
        Page->>Virtualizer: DownEventCard 리스트 전달
        Virtualizer->>Virtualizer: 사용자 모니터 세로 높이 고려
        Virtualizer->>Virtualizer: 화면에 필요한 downEventIds 추출

        Virtualizer-->>Page: Rendering 대상 downEventIds 반환

        Page->>CardAPI: downEventIds로 DownEventCard(Text) 요청
        CardAPI-->>Page: DownEventCard(Text) 반환

        Page->>ContentAPI: downEventIds로 DownEventContent(html) 요청
        ContentAPI-->>Page: DownEventContent(html) 반환
    end

    rect rgb(255, 248, 235)
        Note over Page,ImageAPI: ③ DownEventCard Element Rendering 시 HTML 이미지 추출
        loop 각 DownEventCard Element
            Page->>Page: DownEventCard(Text)와<br/>DownEventContent(html) 결합
            Page->>Page: HTML에서 이미지 식별자 추출
            Page->>ImageAPI: 이미지 식별자별 이미지 요청
            ImageAPI-->>Page: 이미지 데이터 반환
            Page->>Page: 이미지가 포함된 Card Element Rendering
        end
    end

    Page-->>User: 최종 DownEventCard 화면 표시
```
