### 1. Froala 에디터 이벤트 처리 및 이미지 삽입 로직
[down-event-popup.tsx](file:///d:/project-workspace/inform-note-workspace/inform-note-front/src/pages/down-event/ui/down-event-popup.tsx#L409-L457)

Froala는 드래그 & 드롭 및 파일 첨부 메뉴 클릭 시 공통으로 **`image.beforeUpload`** 이벤트를 발생시킵니다. 이 핸들러에서 자체 API를 비동기 호출하고, 기본 업로드를 차단하기 위해 **`return false;`**를 반환하는 것이 핵심입니다.

```typescript
// src/pages/down-event/ui/down-event-popup.tsx 발췌

const instance = new Editor(editorElementRef.current, {
  // 툴바에 이미지 삽입 메뉴(insertImage) 포함
  toolbarButtons: [
    'bold', 'italic', 'underline', '|',
    'insertTable', '|',
    'insertImage', '|', // 👈 이미지 첨부 메뉴
    'undo', 'redo'
  ],
  events: {
    /**
     * 드래그&드롭 및 이미지 첨부 메뉴 선택 시 공통 트리거되는 이벤트
     */
    'image.beforeUpload': function (this: any, images: any) {
      if (!images || images.length === 0) {
        return false;
      }

      const file = images[0]; // 업로드된 File 객체
      const editor = this;    // Froala 에디터 인스턴스

      // 1. 서버의 임시 파일 등록 API 호출 (Multipart FormData 전송)
      registerTempFileApi({
        file,
        refType: 'DOWN_ATTACHMENT',
        assignedTechnician: currentTech,
        refId: itemRef.current?.downEventId,
      })
        .then((res) => {
          // 2. 백엔드 파일 인라인 스트리밍 URL 생성 (/feature/file-handler/view/{fileId})
          const viewUrl = getFileViewUrl(res.fileId);

          // 3. 에디터 본문 커서 위치에 <img> 태그 주입
          //    data-file-id 속성을 함께 심어 저장 시 서버에서 파일 키를 영구 저장 처리할 수 있도록 함
          editor.image.insert(
            viewUrl,
            null,
            {
              'data-file-id': res.fileId,
              'data-name': file.name,
              alt: file.name,
            },
            editor.image.get()
          );
        })
        .catch((err) => {
          console.error('에디터 이미지 업로드 실패:', err);
          setErrorMessage('이미지 업로드에 실패했습니다. 파일 형식이나 용량을 확인해 주세요.');
        });

      // ⚠️ 매우 중요: Froala 기본 데모 서버(i.froala.com)로의 전송을 차단하기 위해 false 반환
      return false;
    },
  },
});
```

### 2. 백엔드 API 호출 함수 (FormData 전송)
[register-temp-file.api.ts](file:///d:/project-workspace/inform-note-workspace/inform-note-front/src/features/editor-file-upload/api/register-temp-file.api.ts)

선택/드롭된 `File` 객체와 메타데이터를 `FormData`로 묶어 서버의 임시 파일 업로드 엔드포인트로 전송합니다.

```typescript
// src/features/editor-file-upload/api/register-temp-file.api.ts
import { axiosInstance } from '@/shared/api'
import { type RegisterTempFileCommand } from '../model/register-temp-file.command'
import { type TempFileRegisteredResponse } from '../model/temp-file-registered.response'

export const registerTempFileApi = async (
  command: RegisterTempFileCommand
): Promise<TempFileRegisteredResponse> => {
  const formData = new FormData()
  formData.append('file', command.file)
  formData.append('refType', command.refType || 'DOWN_ATTACHMENT')
  formData.append('assignedTechnician', JSON.stringify(command.assignedTechnician))
  if (command.refId) {
    formData.append('refId', command.refId)
  }

  // POST /feature/file-handler/register-temp-file/command
  const response = await axiosInstance.post<TempFileRegisteredResponse>(
    '/feature/file-handler/register-temp-file/command',
    formData,
    {
      headers: { 'Content-Type': 'multipart/form-data' },
    }
  )
  return response.data
}
```

### 3. 파일 조회 URL 생성 유틸

### 💡 핵심 처리 포인트 요약
1. **단일 진입점 (`image.beforeUpload`)**: 파일 선택기(메뉴)와 드래그&드롭 모두 동일한 이벤트 핸들러(`image.beforeUpload`)로 들어옵니다.
2. **`return false;` 필수**: 반환하지 않으면 Froala의 기본 데모 엔드포인트(`i.froala.com`)로 전송되어 샘플 이미지가 들어가는 현상이 발생합니다.
3. **`editor.image.insert(url, sanitize, attributes, imageElement)`**: 업로드 완료 후 발급받은 URL과 백엔드 식별용 커스텀 속성(`data-file-id`)을 함께 본문에 삽입합니다.
