**React 16.14.0 + TypeScript** 환경에 맞춘 Froala 에디터 이미지 업로드 연동 코드 예시입니다. 

React 16 환경의 특성(`import React from 'react'` 필수, Hook 라이프사이클)을 준수하여 작성되었습니다.

### 1. API 요청 함수 및 타입 정의

```typescript
// features/editor-file-upload/api/register-temp-file.api.ts
import axios from 'axios';

// TypeScript 인터페이스 정의
export interface RegisterTempFileCommand {
  file: File;
  refType?: string;
  assignedTechnician?: unknown;
  refId?: string;
}

export interface TempFileRegisteredResponse {
  fileId: string;
  fileName: string;
  fileSize: number;
}

// 1. 임시 파일 업로드 API (Multipart FormData)
export const registerTempFileApi = async (
  command: RegisterTempFileCommand
): Promise<TempFileRegisteredResponse> => {
  const formData = new FormData();
  formData.append('file', command.file);
  formData.append('refType', command.refType || 'DOWN_ATTACHMENT');
  
  if (command.assignedTechnician) {
    formData.append('assignedTechnician', JSON.stringify(command.assignedTechnician));
  }
  if (command.refId) {
    formData.append('refId', command.refId);
  }

  const response = await axios.post<TempFileRegisteredResponse>(
    '/feature/file-handler/register-temp-file/command',
    formData,
    {
      headers: { 'Content-Type': 'multipart/form-data' },
    }
  );

  return response.data;
};

// 2. 파일 스트리밍/조회 URL 생성 유틸
export const getFileViewUrl = (fileId: string): string => {
  return `/feature/file-handler/view/${fileId}`;
};
```

### 2. Froala 에디터 컴포넌트 (React 16.14.0 + TS)

React 16에서는 새로운 JSX Transform이 기본 적용되지 않을 수 있으므로 상단 `import React`가 반드시 필요합니다. 또한 컴포넌트 언마운트 시 Froala 인스턴스를 파괴(`destroy`)하는 메모리 정리(cleanup) 로직이 포함됩니다.

```tsx
// components/FroalaImageEditor.tsx
import React, { useEffect, useRef, useState } from 'react';

// Froala 에디터 코어 및 플러그인/CSS 임포트
import FroalaEditor from 'froala-editor';
import 'froala-editor/css/froala_editor.pkgd.min.css';
import 'froala-editor/css/froala_style.min.css';
// 이미지 및 테이블 플러그인 번들
import 'froala-editor/js/plugins/image.min.js';
import 'froala-editor/js/plugins/table.min.js';

import { registerTempFileApi, getFileViewUrl } from './features/editor-file-upload/api/register-temp-file.api';

interface FroalaImageEditorProps {
  refId?: string;
  technician?: unknown;
  initialContent?: string;
  onChange?: (html: string) => void;
}

export const FroalaImageEditor: React.FC<FroalaImageEditorProps> = ({
  refId,
  technician,
  initialContent = '',
  onChange,
}) => {
  const editorRef = useRef<HTMLDivElement | null>(null);
  const instanceRef = useRef<FroalaEditor | null>(null);
  const [errorMessage, setErrorMessage] = useState<string | null>(null);

  useEffect(() => {
    if (!editorRef.current) return;

    // Froala 에디터 인스턴스 초기화
    instanceRef.current = new FroalaEditor(editorRef.current, {
      toolbarButtons: [
        'bold', 'italic', 'underline', '|',
        'insertTable', '|',
        'insertImage', '|', // 이미지 첨부 버튼
        'undo', 'redo'
      ],
      // 이미지 허용 확장자 설정
      imageAllowedTypes: ['jpeg', 'jpg', 'png', 'gif', 'webp'],
      events: {
        'initialized': function (this: any) {
          if (initialContent) {
            this.html.set(initialContent);
          }
        },
        'contentChanged': function (this: any) {
          if (onChange) {
            onChange(this.html.get());
          }
        },
        /**
         * 💡 핵심 로직: 이미지 드래그&드롭 및 파일 첨부 메뉴 선택 시 공통 실행
         */
        'image.beforeUpload': function (this: any, images: FileList | File[]) {
          if (!images || images.length === 0) {
            return false;
          }

          const file = images[0];
          const editor = this; // Froala 에디터 인스턴스

          // 1. 커스텀 백엔드 API로 업로드 요청
          registerTempFileApi({
            file,
            refType: 'DOWN_ATTACHMENT',
            assignedTechnician: technician,
            refId: refId,
          })
            .then((res) => {
              // 2. 서버에서 받은 fileId로 URL 생성
              const viewUrl = getFileViewUrl(res.fileId);

              // 3. 에디터 본문 커서 위치에 <img> 태그 주입
              editor.image.insert(
                viewUrl,
                null,
                {
                  'data-file-id': res.fileId,
                  'data-name': file.name,
                  alt: file.name,
                },
                editor.image.get()
              );
            })
            .catch((err) => {
              console.error('에디터 이미지 업로드 실패:', err);
              setErrorMessage('이미지 업로드에 실패했습니다. 형식 및 용량을 확인해주세요.');
            });

          // ⚠️ Froala 기본 데모 서버(i.froala.com)로의 업로드를 차단하기 위해 false 반환
          return false;
        },
      },
    });

    // Cleanup: React 16 컴포넌트 언마운트 시 에디터 메모리 해제
    return () => {
      if (instanceRef.current) {
        instanceRef.current.destroy();
        instanceRef.current = null;
      }
    };
  }, []); // 마운트 시 1회 실행

  return (
    <div className="froala-container">
      {errorMessage && (
        <div style={{ color: 'red', marginBottom: '8px', fontSize: '13px' }}>
          {errorMessage}
        </div>
      )}
      {/* Froala가 마운트될 DOM 엘리먼트 */}
      <div ref={editorRef} />
    </div>
  );
};
```

### 3. React 16.14.0 환경 핵심 포인트

1. **`import React` 누락 주의**: React 17 이전 환경(16.14.0)은 `React.createElement`로 트랜스파일되므로 컴포넌트 파일마다 `import React` 선언이 필수입니다.
2. **`useEffect` Cleanup (`instance.destroy()`)**: 에디터 인스턴스를 언마운트 시 명시적으로 파괴하지 않으면 SPA 환경(모달 열기/닫기 등)에서 DOM 누수가 발생할 수 있으므로 cleanup을 필수로 배치합니다.
3. **`image.beforeUpload`의 `return false;`**: Froala 기본 업로드 파이프라인을 중단하고 자체 `registerTempFileApi`로 처리하기 위한 필수 조건입니다.
